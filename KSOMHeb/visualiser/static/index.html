K-SOM-Heb interactive companion — the textbook's lab bench

Every tab is an interactive version of a verified experiment: the browser renders, the server integrates with the same ksomheb.py the evidence ledger runs.

This suite is the interactive companion to the K-SOM-Heb textbook (KSOMHeb/textbook/). Each tab pairs one chapter with the verification iteration that grounds it, and turns the experiment's fixed parameters into sliders so the math can be felt: find the transition yourself, flip the fate of the closed loop, break a lock by widening the detuning.

Trust & provenance

The project's discipline is verify, don't assert — nothing in the textbook is claimed without a runnable script behind it. This suite keeps that bar: the browser never integrates the model. All dynamics run server-side in Python and either call the verified ksomheb.py directly or use a reduction that a verification iteration proved equivalent; selfcheck.py re-checks every such step (run it any time: python3 selfcheck.py). There is no second implementation of the model to drift out of parity — that was the weakness of the previous JS visualiser, now archived under legacy/.

Labs

Reading a lab

Each lab has three layers: the interactive (sliders re-run the experiment server-side; the player lets you scrub back through the trajectory — you can rewind through a tipping point), the what-to-notice panel (the chapter's punchlines, stated against what's on screen), and the provenance footer (which chapter it teaches, which verification script witnesses the claim, and the claim itself with its canonical typing where it has one).

Running

pip3 install -r KSOMHeb/requirements.txt (numpy is the only dependency), then python3 KSOMHeb/visualiser/serve.py and open localhost:8000. The server is stdlib-only.

Adding a lab = one Python module under labs/ (metadata + run()), one renderer under static/labs/, one line in the registry. See labs/__init__.py.
